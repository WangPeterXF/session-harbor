Local-first Codex session management

SessionHarbor

Back up every stable Codex session, reclaim local disk space only after verified safety gates, restore raw conversations, and review evidence-linked work from other devices.

View on GitHub Install with Codex Agent index

Three outcomes, one verified vault

Back up every session

Incremental, content-addressed backup to an external drive or mounted NAS with immutable device-owned snapshots.

Free space without blind deletion

Backup and cleanup stay separate. Old local originals become eligible only after inactivity, backup-age, open-file, and fresh hash gates.

Bridge device context

macOS and Windows devices can inspect verified peer inventories and stage only reviewed, evidence-linked context.

Start from a new Codex task

Set up SessionHarbor from https://github.com/WangPeterXF/session-harbor using the pinned v0.3.1 English bootstrap prompt. Verify the owner, tag, license, and plugin before installing. Start with the read-only dashboard and do not mutate any real session or drive without a separate explicit approval.

Copy-ready prompts are available in English and 简体中文.
